# LilyGoGui Demo Features

This demo showcases the following features of the TTGO T-Watch:

*   **Calendar:** A simple calendar application.
*   **Wireless:** Displays WiFi connection status and allows for scanning of networks.
*   **Music:** Provides media control buttons to interact with a connected Bluetooth device.
*   **Mic FFT:** A real-time audio visualizer that displays the Fast Fourier Transform (FFT) of the microphone input.
*   **Radio:** A software-defined radio (SDR) receiver.
*   **Configuration:** Allows for setting various device parameters.
*   **Step Counter:** A pedometer that counts the user's steps.
*   **Battery Voltage:** Displays the current battery voltage.
*   **Mouse:** Turns the watch into a Bluetooth mouse, using the touchscreen as a trackpad.
*   **Keyboard:** Turns the watch into a Bluetooth media keyboard with play/pause, volume, and track controls.
*   **Alarm:** A basic alarm clock application.
